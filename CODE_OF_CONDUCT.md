# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, assume good intent, and keep discussions focused on the work. Harassment and personal attacks aren't tolerated.

Report unacceptable behavior through [GitHub content reporting](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam), choosing to report it to the repository maintainer. All reports are handled confidentially.
