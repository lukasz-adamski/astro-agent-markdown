# Security policy

## Supported versions

Security fixes are released for the latest minor version.

## Reporting a vulnerability

Please don't open a public issue. Report it privately through [GitHub security advisories](https://github.com/lukasz-adamski/astro-agent-markdown/security/advisories/new). Private vulnerability reporting is enabled, so only the maintainer sees the report.

Include the affected version, the configuration and the steps to reproduce. You can expect an initial response within a week. Once a fix is released, the advisory is published with credit to the reporter, unless you prefer to stay anonymous.
